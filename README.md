# 📚 Library Management System - Java OOP

A domain-driven console application built with **Java** demonstrating core **Object-Oriented Programming (OOP)** principles, clean class hierarchies, design patterns, and Java Collections Framework.

## ✨ Core Features & Domain Rules

- **Object-Oriented Design:** Comprehensive UML class hierarchy modeling real-world library entities (`Book`, `Journals`, `StudyBooks`, `Magazines`, `Person`, `Librarian`, `Reader`, `Author`, `Member Record`).
- **Book & Inventory Management:** Add, search (by ID, title, or author), update, delete, and filter books by categories/authors.
- **Lending & Return Logic:** Track borrowed books per reader, enforce a maximum 5-book borrowing limit per member, and manage book availability status.
- **Billing & Fine System:** Automatic bill generation upon checkout and fee refunds on valid book returns.
- **Java Collections Framework:** Applied `List`, `Set`, and `Map` data structures for efficient data management, lookup, and uniqueness constraints.
- **OOP Fundamentals:** Strict encapsulation, composition, inheritance, abstract classes/interfaces, and polymorphic behaviors.

## 🛠️ Tech Stack

- **Language:** Java 17+
- **Paradigm:** Object-Oriented Programming (OOP)
- **Data Structures:** Java Collections (`List`, `Set`, `Map`)
- **Tools:** Git, IntelliJ IDEA, Maven

## ⚙️ Getting Started

### Prerequisites

Make sure you have JDK 17 or higher installed on your machine.

### Local Execution

1. Clone the repository:
   git clone https://github.com/ggozdekocer/library-management-system.git
   cd library-management-system

2. Compile the application:
   javac -d bin src/**/*.java

3. Run the console app:
   java -cp bin Main
